## 문제
1번부터 N번까지 N개의 풍선이 원형으로 놓여 있고. i번 풍선의 오른쪽에는 i+1번 풍선이 있고, 왼쪽에는 i-1번 풍선이 있다. 단, 1번 풍선의 왼쪽에 N번 풍선이 있고, N번 풍선의 오른쪽에 1번 풍선이 있다. 각 풍선 안에는 종이가 하나 들어있고, 종이에는 -N보다 크거나 같고, N보다 작거나 같은 정수가 하나 적혀있다. 이 풍선들을 다음과 같은 규칙으로 터뜨린다.

우선, 제일 처음에는 1번 풍선을 터뜨린다. 다음에는 풍선 안에 있는 종이를 꺼내어 그 종이에 적혀있는 값만큼 이동하여 다음 풍선을 터뜨린다. 양수가 적혀 있을 경우에는 오른쪽으로, 음수가 적혀 있을 때는 왼쪽으로 이동한다. 이동할 때에는 이미 터진 풍선은 빼고 이동한다.

예를 들어 다섯 개의 풍선 안에 차례로 3, 2, 1, -3, -1이 적혀 있었다고 하자. 이 경우 3이 적혀 있는 1번 풍선, -3이 적혀 있는 4번 풍선, -1이 적혀 있는 5번 풍선, 1이 적혀 있는 3번 풍선, 2가 적혀 있는 2번 풍선의 순서대로 터지게 된다.

## 입력
첫째 줄에 자연수 N(1 ≤ N ≤ 1,000)이 주어진다. 다음 줄에는 차례로 각 풍선 안의 종이에 적혀 있는 수가 주어진다. 종이에 0은 적혀있지 않다.

## 출력
첫째 줄에 터진 풍선의 번호를 차례로 나열한다.

## 예제 입력 1 
5 <br />
3 2 1 -3 -1

## 예제 출력 1 
1 4 5 3 2

## Answer
```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int N = scanner.nextInt();

        Deque<Integer> deque = new ArrayDeque<>();
        int[] inner = new int[N];
        StringBuilder sb = new StringBuilder();

        for (int i = 1; i <= N; i++) {
            deque.add(i);
            int input = scanner.nextInt();
            inner[i - 1] = input;
        }
        sb.append(deque.remove() + " ");
        int move = inner[0];
        for (int i = 0; i < N - 1; i++) {
            if (move > 0){
                for (int j = 1; j < move; j++) {
                    Integer remove = deque.removeFirst();
                    deque.addLast(remove);
                }
                Integer integer = deque.removeFirst();
                move = inner[integer - 1];
                sb.append(integer + " ");
            } else if (move < 0) {
                for (int j = -1; j > move; j--) {
                    Integer remove = deque.removeLast();
                    deque.addFirst(remove);
                }
                Integer integer = deque.removeLast();
                move = inner[integer - 1];
                sb.append(integer + " ");
            }
            if (deque.size() == 1){
                sb.append(deque.remove());
                break;
            }
        }
        System.out.println(sb);
    }
}
```
이 문제는 풍선을 Deque에 놓고 내부에 있는 정수 카드를 int[] 배열을 통해 저장하였다.

최초 1번째 풍선을 터트리기 위해 시작 전 1번째 풍선을 `StringBuilder`에 저장해두고 시작한다.

이후 나온 정수 카드의 숫자를 N이라 할 때 int[N - 1]을 통해 찾아낸 후 양수일 경우 1부터, 음수일 경우 -1부터 시작하여 양수라면 deque에서 앞 숫자를 빼고 뒤로, 음수라면 뒤 숫자를 빼고 앞으로 보내는 식으로 하여 맨 앞에 나온 숫자를 출력해주는 형식으로 하였다.
