## 문제
재귀적인 패턴으로 별을 찍어 보자. N이 3의 거듭제곱(3, 9, 27, ...)이라고 할 때, 크기 N의 패턴은 N×N 정사각형 모양이다.

크기 3의 패턴은 가운데에 공백이 있고, 가운데를 제외한 모든 칸에 별이 하나씩 있는 패턴이다.

```text
***
* *
***
```
N이 3보다 클 경우, 크기 N의 패턴은 공백으로 채워진 가운데의 (N/3)×(N/3) 정사각형을 크기 N/3의 패턴으로 둘러싼 형태이다. 예를 들어 크기 27의 패턴은 예제 출력 1과 같다.

## 입력
첫째 줄에 N이 주어진다. N은 3의 거듭제곱이다. 즉 어떤 정수 k에 대해 N=3k이며, 이때 1 ≤ k < 8이다.

## 출력
첫째 줄부터 N번째 줄까지 별을 출력한다.

## 예제 입력 1 
27

## 예제 출력 1 
```text
***************************
* ** ** ** ** ** ** ** ** *
***************************
***   ******   ******   ***
* *   * ** *   * ** *   * *
***   ******   ******   ***
***************************
* ** ** ** ** ** ** ** ** *
***************************
*********         *********
* ** ** *         * ** ** *
*********         *********
***   ***         ***   ***
* *   * *         * *   * *
***   ***         ***   ***
*********         *********
* ** ** *         * ** ** *
*********         *********
***************************
* ** ** ** ** ** ** ** ** *
***************************

* *   * ** *   * ** *   * *
***   ******   ******   ***
***************************
* ** ** ** ** ** ** ** ** *
***************************
```

## Answer
```java
import java.util.Scanner;

public class Main {
    static String[][] star;
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        int N = scanner.nextInt();
        star = new String[N][N];

        star(N, 0, 0);

        StringBuilder sb = new StringBuilder();

        for (int i = 0; i < star.length; i++) {
            for (int j = 0; j < star.length; j++) {
                sb.append(star[i][j]);
            }
            sb.append("\n");
        }

        System.out.print(sb);
    }

    private static void star(int n, int row, int col) {
        if (n <= 1){
            star[row][col] = "*";
            return;
        }
        for (int i = 0; i < 3; i++) {
            for (int j = 0; j < 3; j++) {
                if (i == 1 && j == 1){
                    empty(n / 3, row + i * (n / 3), col + j * (n / 3));
                } else {
                    star(n / 3, row + i * (n / 3), col + j * (n / 3));
                }
            }
        }
    }

    private static void empty(int n, int row, int col) {
        for (int i = row; i < row + n; i++) {
            for (int j = col; j < col + n; j++) {
                star[i][j] = " ";
            }
        }
    }
}
```
해당 문제는 배열과 재귀를 활용하여 풀어낼 수 있다. 재귀를 학습하기 좋은 문제이니 추후 재귀 학습 시 해당 문제를 다시 한 번 풀어보는 것도 좋을 것 같다.
