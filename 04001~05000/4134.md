## 문제
정수 n(0 ≤ n ≤ 4*109)가 주어졌을 때, n보다 크거나 같은 소수 중 가장 작은 소수 찾는 프로그램을 작성하시오.

## 입력
첫째 줄에 테스트 케이스의 개수가 주어진다. 각 테스트 케이스는 한 줄로 이루어져 있고, 정수 n이 주어진다.

## 출력
각각의 테스트 케이스에 대해서 n보다 크거나 같은 소수 중 가장 작은 소수를 한 줄에 하나씩 출력한다.

## 예제 입력 1 
3 <br />
6 <br />
20 <br />
100 <br />

## 예제 출력 1 
7 <br />
23 <br />
101 <br />

## Answer
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args)  {
        Scanner scanner = new Scanner(System.in);

        int T = scanner.nextInt();

        long[] numbers = new long[T];

        for (int i = 0; i < T; i++) {
            long number = scanner.nextLong();
            numbers[i] = number;
        }

        for (int i = 0; i < numbers.length; i++) {
            long target = numbers[i];

            if (target <= 2) {
                System.out.println(2);
                continue;
            }

            while(true){
                boolean prime = true;
                for (long div = 2; div * div <= target; div++) {
                    if (target % div == 0) {
                        prime = false;
                        break;
                    }
                }
                if (prime) { System.out.println(target); break; }
                target++;
            }
        }
    }
}
```

✅ 소수 판정에서 검사 범위는 왜 √n 까지인가?
### 1. 소수의 정의

**소수(prime number)** 란

1과 자기 자신 외에는 나누어 떨어지지 않는 수

즉, 어떤 수 n이 소수가 아니라면
→ n = a × b 형태로 표현할 수 있고
→ 이때 a, b는 모두 1과 n이 아닌 약수다.

### 2. 약수는 항상 “쌍(pair)”으로 존재한다

어떤 수 n이 합성수라면, 약수는 항상 쌍으로 존재한다.

예시:

36 = 2 × 18

36 = 3 × 12

36 = 4 × 9

36 = 6 × 6

👉 여기서 중요한 사실:

한 쪽 약수는 작고

다른 한 쪽은 큼

### 3. 핵심 아이디어: √n 기준

약수 쌍 (a, b)에서

만약 a > √n 이면

반드시 b < √n 이다.

즉,

약수가 존재한다면, 반드시 √n 이하의 약수가 하나는 존재한다

예시 (n = 36)

√36 = 6

(2,18) → 2 ≤ 6

(3,12) → 3 ≤ 6

(4,9) → 4 ≤ 6

(6,6) → 6 ≤ 6

👉 모든 약수 쌍은 √n을 기준으로 한쪽이 반드시 작다

### 4. 그래서 검사 범위는 √n 까지만 보면 된다

소수 판정을 할 때:

2 ~ √n 사이에서

한 번이라도 나눠지면 → 합성수

끝까지 안 나눠지면 → 소수

그 이후(√n 초과)는:

이미 검사한 약수들의 “짝”이기 때문에

중복 검사일 뿐, 새로운 정보가 없다

### 5. 코드로 표현하면
```java
for (long div = 2; div * div <= n; div++) {
    if (n % div == 0) {
        // 합성수
    }
}
```


`div * div <= n`
→ `div <= √n` 과 같은 의미

성능과 정확도를 동시에 만족하는 범위

### 6. 한 줄 요약 (암기용)

소수가 아니라면, √n 이하에 반드시 약수가 있다.
그래서 소수 판정은 √n까지만 검사하면 충분하다.
