## 문제
정수를 저장하는 덱을 구현한 다음, 입력으로 주어지는 명령을 처리하는 프로그램을 작성하시오.

명령은 총 여덟 가지이다.

1 X: 정수 X를 덱의 앞에 넣는다. (1 ≤ X ≤ 100,000) <br />
2 X: 정수 X를 덱의 뒤에 넣는다. (1 ≤ X ≤ 100,000) <br />
3: 덱에 정수가 있다면 맨 앞의 정수를 빼고 출력한다. 없다면 -1을 대신 출력한다. <br />
4: 덱에 정수가 있다면 맨 뒤의 정수를 빼고 출력한다. 없다면 -1을 대신 출력한다. <br />
5: 덱에 들어있는 정수의 개수를 출력한다. <br />
6: 덱이 비어있으면 1, 아니면 0을 출력한다. <br />
7: 덱에 정수가 있다면 맨 앞의 정수를 출력한다. 없다면 -1을 대신 출력한다. <br />
8: 덱에 정수가 있다면 맨 뒤의 정수를 출력한다. 없다면 -1을 대신 출력한다. <br />

## 입력
첫째 줄에 명령의 수 N이 주어진다. (1 ≤ N ≤ 1,000,000)

둘째 줄부터 N개 줄에 명령이 하나씩 주어진다.

출력을 요구하는 명령은 하나 이상 주어진다.

## 출력
출력을 요구하는 명령이 주어질 때마다 명령의 결과를 한 줄에 하나씩 출력한다.

## 예제 입력 1 
11 <br />
6 <br />
1 3 <br />
1 8 <br />
7 <br />
8 <br />
3 <br />
2 5 <br />
1 2 <br />
5 <br />
4 <br />
4 <br />

## 예제 출력 1 
1 <br />
8 <br />
3 <br />
8 <br />
3 <br />
5 <br />
3 <br />

## Answer
```java

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.LinkedList;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        LinkedList<Integer> list = new LinkedList<>();

        int N = Integer.parseInt(br.readLine());

        StringBuilder sb = new StringBuilder();

        for (int i = 0; i < N; i++) {
            String order = br.readLine();
            if (order.startsWith("1")){
                int n = Integer.parseInt(order.split(" ")[1]);
                list.addFirst(n);
            } else if (order.startsWith("2")) {
                int n = Integer.parseInt(order.split(" ")[1]);
                list.addLast(n);
            } else {

            }
            switch (order){
                case "3":
                    if (!list.isEmpty()){
                        Integer remove = list.remove(0);
                        sb.append(remove + "\n");
                        break;
                    } else {
                        sb.append(-1 + "\n");
                        break;
                    }
                case "4":
                    if (!list.isEmpty()){
                        Integer remove = list.remove(list.size() - 1);
                        sb.append(remove + "\n");
                        break;
                    } else {
                        sb.append(-1 + "\n");
                        break;
                    }
                case "5":
                    sb.append(list.size() + "\n");
                    break;
                case "6":
                    if (list.isEmpty()){
                        sb.append(1 + "\n");
                        break;
                    } else {
                        sb.append(0 + "\n");
                        break;
                    }
                case "7":
                    if (!list.isEmpty()){
                        sb.append(list.get(0) + "\n");
                        break;
                    } else {
                        sb.append(-1 + "\n");
                        break;
                    }
                case "8":
                    if (!list.isEmpty()){
                        sb.append(list.get(list.size() - 1) + "\n");
                        break;
                    } else {
                        sb.append(-1 + "\n");
                        break;
                    }
            }
        }

        System.out.println(sb);
    }
}
```
